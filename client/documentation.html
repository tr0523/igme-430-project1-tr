/getByName

Relative URL:

/getByName

Supported Methods:

Get, Partially Head

QueryParams:

name (string, required, the name of the pokemon)

Returns:

a JSON pokemon object

(Format: {id:number,num:string,name:string,img:string,type:[string],height:string,weight:string,weaknesses:[string],"next_evolution":[{num:string,name:string}]})

Example:

Request: /getByName?name=Bulbasaur
